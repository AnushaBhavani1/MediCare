# 🏥 MediCare – Healthcare Web Application

MediCare is a full-stack healthcare platform built using **React.js, Node.js, Express.js, and MongoDB**. The application enables secure appointment booking, role-based access control, and efficient patient management through a modern and responsive interface.

---

## 🚀 Features

* 🔐 JWT-based authentication and authorization
* 👥 Role-based access control for Admin and Users
* 📅 Appointment booking and management
* 🩺 Doctor listing and scheduling
* 📋 Patient record management
* ⚡ 10+ RESTful APIs for seamless data operations
* 📱 Responsive and user-friendly interface
* ☁️ Cloud deployment using Render
* 🔒 Secure environment variable configuration

## 🔧 Installation

### Clone the Repository

```bash
git clone https://github.com/AnushaBhavani1/MediCare.git
```

### Navigate to the Project Directory

```bash
cd MediCare
```

### Install Dependencies

```bash
npm install
```

### Start the Backend

```bash
npm run server
```

### Start the Frontend

```bash
npm run dev
```
